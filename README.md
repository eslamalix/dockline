# Dockline

Dockline is a glass widget bar for the edge of the Windows 11 screen: music controls for any app, a focus timer, battery, CPU and RAM, Night Light, radio and quick actions. It never changes your taskbar, Start menu or File Explorer.

Get it on the Microsoft Store: https://apps.microsoft.com/detail/9P75PDWDBD1K (7-day free trial, one price, no subscription).

## Suggest a widget, vote for the next one

New widgets come about every two weeks, free for everyone who bought Dockline. You choose which one comes next.

1. Open [Ideas](https://github.com/eslamalix/dockline/discussions/categories/ideas).
2. If your widget is already there, give it an upvote (the arrow on the left).
3. If it is not, choose **New discussion** and fill in the short form.

The idea with the most votes is built next. When it ships, the discussion is marked as answered.

## Report a problem

Open a [bug report](https://github.com/eslamalix/dockline/issues/new?template=bug.yml). Please say your Windows version and what you saw.
